Encryption and identity check Signum to Signum only · off by default

        

        
NOT compatible with SCS. 

        

        

          
Protection (now)

          
verify: every P2/P3 link to another Signum checks the other station's key at link start (the same keys and handshake as encryption), then the data goes in clear; no acknowledgement; a link where the check cannot be made (the reference unit, an older Signum, an untrusted key) is ended. On: every link is encrypted, or ended with the reason, never sent in clear; the first On asks for the acknowledgement NOT-AMATEUR; once given it is stored in the settings file and On (and Off) act at once. Not while a link is up; this run

          
Protection at next start

          
writes encryption = verify or encryption = on to the settings file (On: and encryption-ack = NOT-AMATEUR, after the acknowledgement, when it is not stored yet); Off removes the line; default off · 

          
Sign every record

          
verify only: on adds a 16-byte authentication tag to every record (the data still in clear; a bad tag ends the link; used when either Signum asks for it); off (default): the identity is checked at link start only, and a station taking the link over after the check is NOT detected. No extra effect with encryption on (every record is authenticated anyway); from the next link

          
Acknowledgement

          
NOT-AMATEUR, given once, is kept in the settings file so that encryption and its options can be turned on and off without typing it again; withdrawing it also turns encryption off · 

          
Compression

          
compress before encrypting (zstd with an English dictionary), used when both Signums have it on; default on; from the next link

          
Trust (encryption)

          
first contact (default): a new station's key is stored, not verified, at the first link (compare the SAS); stored only: only stations whose key is already stored here; verified only: links only with stations whose key you marked verified

          
Trust (verify)

          
the identity check's policy: stored only (default): only a key already stored here passes; first contact: a new station's key is stored, not verified, and the link goes on; verified only: only keys you marked verified. A "*" pre-shared key alone passes only with first contact (it does not show which station this is)

          
Set-up timeout (s)

          
the other station's capability record and the handshake, each at most this long, 10-600; default 60; then the link is ended

          
Key directory

          
where the keys are kept (mode 0700); applies at next start; default ~/.config/signum/keys · 

        

        

        
Signing, compression, trust and the timeout apply at once, for this run; Keep live settings at next start (top of this tab) writes them to the settings file too.

Fingerprint
—

        

          
          
          
          
          
        

        
        

        
The public key is not secret: give it to the other operator any way you like, then read the fingerprint to each other by telephone or in person. The private key never leaves this computer unless you export it (to move the station).

Imported public keys are stored as NOT verified: verify each one under Known stations after comparing the fingerprint.

Received over the air not trusted until you accept

        
—

        
A key that arrived over the air could come from anyone. Review shows its fingerprint: compare it with the other operator by another channel before you accept it as verified.

      

      
Pre-shared keys secret: give them only by a safe channel

Name
          

        

        

        

        
A random key is stronger than a passphrase. The 4-character id is the same at both ends when the keys are the same. Export shows the block to give to the other operator (in person, encrypted mail; never over the air).

Signum

  
A P1/P2/P3 HF data modem with the classic host-mode interface, for Pat and serial terminals.

  
Signum is an independent program. It is not a product of, affiliated with or supported by any modem manufacturer. Do not ask them for help with it.
